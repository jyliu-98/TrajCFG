# Required assets

Only the image-conditioned examples require input assets. The example images are hosted in the project-page repository to avoid duplicating binary files.

| Task/backbone | Required input |
|---|---|
| Wan2.2-TI2V-5B (I2V) | [Image](https://jyliu-98.github.io/trajcfg-project-page/assets/gallery/i2v/pai_g_wan22_5b/input.jpeg) |
| Wan2.2-I2V-A14B | [Image](https://jyliu-98.github.io/trajcfg-project-page/assets/gallery/i2v/pai_g_wan22_14b/input.jpeg) |
| Cosmos-Predict2.5-2B | [Image](https://jyliu-98.github.io/trajcfg-project-page/assets/gallery/i2v/pai_g_cosmos/input.jpeg) |
| Hunyuan3D-2 | [Image](https://jyliu-98.github.io/trajcfg-project-page/assets/gallery/i2-3d/386.jpeg) and the shape mesh generated by `examples/i2_3d/shape.py` |

The Hunyuan3D-2 texture example uses `outputs/i2_3d_shape.glb` by default. Pass `--image` or `--mesh` to use local assets instead.
